🏦 Bank Account Management System using Python

📌 About the Project

The Bank Account Management System is a beginner-friendly Python project that simulates basic banking operations. It allows users to create an account, deposit money, withdraw money, and check their account balance after verifying their PIN.

This project was developed to practise Object-Oriented Programming (OOP) concepts in Python, especially classes, objects, constructors, methods, and encapsulation.

✨ Features

- Account Creation: Enter the account holder's name, PIN, and initial balance.
- PIN Verification: Verify the PIN before performing banking operations.
- Deposit Money: Add money to the account after successful PIN verification.
- Withdraw Money: Withdraw money if the account has a sufficient balance.
- Balance Enquiry: View the account holder's name and current balance after PIN verification.
- Input Validation: Prevent invalid deposit and withdrawal amounts.

🛠️ Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Python IDLE

🧠 Concepts Practised

- Classes and Objects
- Constructor ("__init__")
- Instance Methods
- "self" keyword
- Encapsulation
- Conditional Statements ("if", "elif", "else")
- User Input ("input()")
- Type Conversion ("float()")

▶️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the Python file in Python IDLE or another Python editor.
4. Run the program.
5. Enter the account holder's name, create a PIN, and enter the initial balance.
6. Choose an operation from the displayed menu.
7. Enter the correct PIN when prompted.
